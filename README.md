# Financy

O **Financy** é uma aplicação de controle financeiro desenvolvida para facilitar o gerenciamento de receitas, despesas e da vida financeira de forma simples e intuitiva.

## 🚀 Projeto em Produção

A aplicação está disponível em produção no endereço:

**🔗 https://financy.aizen.dev.br/**

O domínio `financy.aizen.dev.br` está ativo e acessível como ambiente oficial da aplicação. <Cite ref=turn314853search0/>

## Tecnologias

- Node.js
- React + TypeScript
- Vite
- Docker
- Terraform
- AWS S3, CloudFront, Route53
- GitHub Actions (CI/CD)

## Como executar localmente

### Frontend

```bash
npm install
npm run dev
```

### Build

```bash
npm run build
```

## Deploy

O deploy é realizado automaticamente através do **GitHub Actions** sempre que alterações são enviadas para a branch principal (`main`).
